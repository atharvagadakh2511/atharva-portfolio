ATHARVA GADAKH — PORTFOLIO STARTER

FILES
- index.html : website content and sections
- style.css  : responsive styling, layout and animations
- script.js  : mobile navigation, scroll reveal and current year

RUN LOCALLY
1. Extract this ZIP.
2. Open the atharva-portfolio folder.
3. Double-click index.html to preview in your browser.
   Recommended: use Visual Studio Code + the Live Server extension.

PERSONALIZE BEFORE PUBLISHING
1. In index.html, replace YOUR_EMAIL@example.com with your real email.
2. Add your resume PDF in this folder and name it exactly: resume.pdf
3. Review project descriptions, years, skills and links for accuracy.
4. Add a professional photo if you want one; the current hero uses an abstract code illustration.

FREE DEPLOYMENT
GitHub Pages:
1. Create a new public GitHub repository, e.g. atharva-portfolio.
2. Upload index.html, style.css, script.js and (optionally) resume.pdf to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for the published URL shown in Settings → Pages.

NOTE
This is a static HTML/CSS/JavaScript site. No paid backend or hosting is required.
